### Business Logic Flow
```
1. ดึงข้อมูลจาก Oracle View (ภาคการศึกษาปัจจุบัน)
   ↓
2. เปรียบเทียบกับ Master Data ใน Moodle DB
   ↓
3. ระบุการเปลี่ยนแปลง:
   • ADD: มีใน Oracle ไม่มีใน Master (หรือ inactive)
   • DEL: มีใน Master (active) แต่ไม่มีใน Oracle
   • SKIP: ไม่มีการเปลี่ยนแปลง
   ↓
4. อัพเดท Master Data (INSERT/UPDATE)
   ↓
5. สร้างไฟล์ CSV สำหรับ Moodle Flat File
   Format: operation,role,user_idnumber,course_idnumber
   ↓
6. Execute Moodle Flat File Task
   php74 scheduled_task.php --execute='\enrol_flatfile\task\flatfile_sync_task'
   ↓
7. บันทึก Log + Statistics + Errors
```
